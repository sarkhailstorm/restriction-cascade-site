Restriction Cascade for Confluence

Confluence passes view restrictions down the page tree, but not edit restrictions. Restriction Cascade hands a page's editors down to every page, folder, whiteboard and database below it, automatically.

Get started

Follows the page tree

Pages created, moved, copied or restored below a root get its editors within about a minute.

Never touches view

It only grants or removes edit. Pages limited to some viewers stay limited.

Built for admins

Merge, mirror or exclude, preview first, switch it per space, and see every change in a 90-day log.

Runs on Atlassian

No external servers and no data leaving Atlassian. Everything lives in Atlassian's Forge platform. Read the privacy policy.

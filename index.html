Features

Everything a space admin needs

Pick how strict a cascade should be, see what it will do first, and keep a record of every change.

Merge

Pages anyone could edit get the root's editors. Pages that already restrict editing keep their editors and gain the root's.

Mirror

Every page gets exactly the root's editors. Anyone else listed as an editor is changed to view-only, so nobody loses view access.

Exclude

Shield a page and everything below it from a cascade set higher up. Roots can be nested, and the nearest one decides.

Automatic

New, moved, copied and restored content is restricted within about a minute, and an hourly check catches anything Confluence did not report.

Preview, then apply

See exactly what would change before anything does. Apply to existing pages in one click and stop a run at any time.

Activity log

Every change is kept for 90 days: what changed, on which page, whose access, and what triggered it.

How it works

Set it up in three steps

  1. Restrict the parent page

    Open the page whose editors should apply below it and choose who may edit: Share → Specific access.

  2. Make it a cascade root

    From the page's ••• menu choose Apps → Restriction Cascade, then pick Merge or Mirror.

  3. Apply once, then relax

    Apply to bring existing pages in line. From then on, new and moved pages follow on their own.

Clear results

Safety

Careful by design

Permissions are serious. Restriction Cascade only ever adds editors or changes them to view-only, and checks its work.

Never changes who can viewPages limited to some viewers stay limited, and edit access only goes to people who can already view.

Never deletes permission entriesMirror changes extra editors to view-only instead of removing them.

Stops on conflictsIt re-reads each page just before writing, and logs a conflict instead of acting on stale data.

Verifies every writeAfter each change it reads the page again to check the result.

No new powersOnly people who can edit the root and administer its space can set up a cascade.

FAQ

Common questions

Does it change who can view a page?

No. It only grants or removes edit access. Pages limited to some viewers stay limited, and it only gives edit access to people who can already view the page.

What is the difference between Merge and Mirror?

Merge adds the root's editors and keeps anyone a page already lists. Mirror makes every page match the root exactly and changes anyone else to view-only. Nobody loses view access with either.

How quickly are new pages restricted?

Usually within about a minute. Confluence can report new pages up to about three minutes late, so a brand-new page can briefly be editable by everyone in the space.

Does any data leave Atlassian?

No. The app runs entirely on Atlassian's Forge platform. We operate no servers and cannot see your content. See the privacy policy.

Which Confluence plans does it work on?

Confluence Cloud Standard, Premium and Enterprise. Confluence Free has no page restrictions, so there is nothing to cascade.

What happens if I uninstall it?

Restrictions the app has set stay on your pages. Atlassian deletes the app's stored data 28 days after uninstall.
